# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.

# Blog Site

Now that you've learned how to work with components in React, it's time to build something and put those skills to use! Your goal for this lab is to make a static site in React to practice building components, writing JSX, and passing down data as props.

You are working with a client to help them create a personal blog website. You are given an outline of how the page looks as well as the different components needed. The information about the blog will be contained in blog.js and imported to app.js. Using props make sure to pass down from app.js into your other components that need it.

### Task 1: Define the Problem
Create a personal blog
### Task 2: Determine the Design
Determine Component Tree
Isolate/develop design per component
### Task 3: Develop the Code 
Create files for each component
Connect each component
Develop each component
### Task 4: Test and Refine 
Debugging and testing during coding 
### Task 5: Document and Maintain 


- ## Prerequisites

- Node.js 18+ installed
- npm available on your machine
- Git installed for cloning the repository

# Clone and run locally

1. Open a terminal.
2. Clone the repository:

   ```bash
   git clone git@github.com:Enoch-Wanjala/blog-site.git
   cd blog-site
   ```
3. Install dependencies:

   ```bash
   npm install
   ```
4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the app in your browser:

   ```
   http://localhost:5173
   ```
